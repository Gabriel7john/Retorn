## 📖 Sobre o projeto

O **Retorn** nasceu da necessidade de ter controle sobre o dinheiro sem complicação. Você registra seus gastos e o app faz as contas por você, mostrando para onde seu dinheiro está indo.

O projeto tem visual **preto com detalhes em vermelho** e, por enquanto, roda inteiramente no front-end. O backend será adicionado nas próximas etapas (veja o [Roadmap](#-roadmap)).

## ✨ Funcionalidades

- Cálculo automático dos gastos
- Registro e listagem de despesas
- Total atualizado em tempo real
- Interface responsiva e de leitura rápida

## 🚀 Como rodar

Não precisa instalar nada. Basta clonar e abrir no navegador:

```bash
# Clone o repositório
git clone https://github.com/SEU-USUARIO/retorn.git

# Entre na pasta
cd retorn

# Abra o index.html no navegador
```

Se preferir um servidor local, com a extensão **Live Server** do VS Code ou:

```bash
npx serve .
```
